Hermes Agent Cloud

My personal Hermes Agent cloud deployment project.

Project Goal

Set up a personal Hermes Agent on an independent cloud Linux server.

Requirements

- 24/7 cloud availability, subject to free hosting limits.
- Control the agent from an Android phone using Telegram.
- No need to keep a laptop or phone running as the server.
- Prefer a free hosting solution with no credit card requirement.
- Keep API keys, passwords and private tokens secure.
